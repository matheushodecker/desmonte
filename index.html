Folha 02 · Vista explodida

O motor,
peça por peça

Este site é uma máquina pequena. Cada peça do motor é uma técnica que faz a página funcionar. Role para separá-las.

      Uma API para tudo

      Propriedades, keyframes e easings, cada um com seus próprios parâmetros, em uma única chamada de animate().

      • Parâmetros por propriedade
      • Keyframes
      • Easings

      Movimentos que se somam

      Com composition: 'blend', uma animação nova se mistura à que já está rodando. Passe o ponteiro sobre a tela.

      • Composição
      • Modificadores
      • Timer

      O scroll vira tempo

      onScroll liga a posição da página ao progresso de uma animação. Role devagar e veja as órbitas.

      • onScroll
      • createDrawable
      • stagger

      Atrasos em grade

      stagger distribui tempos e valores por uma grade, a partir de qualquer ponto. Clique numa célula.

      • Grade
      • Origem
      • Valores escalonados

      Ferramentas de SVG

      Desenhe traços, siga caminhos e transforme formas com createDrawable, createMotionPath e morphTo.

      • Desenho de linhas
      • Caminho de movimento
      • Transformação de formas

      Arraste com mola

      createDraggable com uma mola na soltura. Puxe a peça do centro da tela e solte.

      • Configurações
      • Molas
      • Callbacks

      Sequência sincronizada

      Uma timeline posiciona cada animação no tempo, como um sequenciador de bateria.

      • Timeline
      • Posições no tempo
      • Posições escalonadas

      Responsivo por escopo

      createScope refaz as animações quando uma media query muda. Gire o celular ou use o botão na tela.

      • Scope
      • Media queries
      • Adaptador Three.js
